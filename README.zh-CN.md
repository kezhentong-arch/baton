# 一棒到底 · Baton

**一件事，一个人，带着 AI，一棒到底。**

[English](README.md) · [文章：AI 写得飞快，你的团队为什么还是这么慢？](docs/essay.zh-CN.md) · 介绍视频：_即将上线_

多数团队做事还像接力赛：一个人写需求，交给下一个人开发，再交给第三个人测试。每交一次棒，就漏一点、等一阵。在「执行」最贵的年代，这笔账是划算的；现在执行大多由 AI 完成，这笔账反过来了。

**一棒到底**是一套给「人人都在用 AI 干活的小团队」的协作方式，外加让它落得了地的两个看板：

- **一条规矩。** 一件事，谁发起，谁负责到底：业务、产品、UI、开发、测试，带着 AI 自己做完。交接是例外。
- **个人看板：管你和你的 AI。** 每个 AI 对话一开始就自己归到一个目标、一个环节上；每件事到哪一步一眼看清；要进下一个环节，AI 先问你，你点头才进。
- **团队看板：管人和人。** 谁负责什么、一件事拆成了哪几块、每个环节花了多久、谁在等谁。不填表：你用说的，AI 来录。

两个看板都通过 MCP 接入你的 AI 工具（Claude Code、Codex 等）。

## 仓库里有什么

| 目录 | 是什么 |
|---|---|
| [`personal-board/`](personal-board/) | 个人看板。只用 Python 标准库，跑在自己电脑上，数据是本地一个 SQLite 文件。 |
| [`team-board/`](team-board/) | 团队看板。一个小的 FastAPI 应用。本地免登录试用，或部署到团队自己的服务器、每人一个令牌。 |
| [`skills/`](skills/) | Skill：教 Claude Code 在这套方式下怎么配合你，什么时候记录，什么时候必须先问你。 |
| [`examples/`](examples/) | 这两个看板自己是怎么用这套方式做出来的：一份真实记录（人名已替换），可以灌进个人看板看。 |
| [`docs/`](docs/) | 文章：传统分环节协作为什么在 AI 时代失效，新的协作模式是什么。 |

## 两分钟跑起来

个人看板（Python 3.11 以上，不用装任何东西）：

```bash
cd personal-board
./board init --lang zh --name 林夏 --letter L
./board seed                            # 示例数据：一个虚构的三人团队
./board start                           # http://127.0.0.1:10990
```

团队看板：

```bash
cd team-board
python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt
python3 -m team_board init --lang zh
python3 -m team_board seed
python3 -m team_board start             # http://127.0.0.1:10890
```

再把看板接进你的 AI（细节见各目录的说明）：

```bash
claude mcp add -s user personal-board -- python3 /绝对路径/personal-board/cli/mcp.py
```

示例数据是一个虚构团队在做一款宠物照护 App，这套方式要处理的几种情形都在里面：一个人把一个目标从头做到尾；一个目标拆成几个整包、交给不同的人各自负责；一块要等另一块；一件长期的事交给一个人、由他自己拆。

想看一份真实的，把研发过程记录灌进一个空的个人看板：

```bash
./board seed --case ../examples/making-of.zh.json --adopt-config
```

## 几样东西怎么配合

```
你 ── 说话 ──▶ 你的各个 AI 对话 ── MCP ──▶ 个人看板    （细到每小时，只给自己看）
                                              │  收工时，你点头
                                              ▼
              同事的 AI ── MCP ──▶          团队看板    （每件事一行摘要）
```

个人看板可以单独用；有团队时再连上团队看板。

## 隐私与部署

所有东西都跑在你自己控制的机器上。个人看板只监听 `127.0.0.1`。团队看板没开令牌登录时拒绝对外监听，`init` 会给每个人生成随机令牌。没有任何数据上报，也没有托管服务。

## 现状

这两个看板是写它的团队每天在用的，也还很年轻，会有粗糙的地方。欢迎提 issue 和 PR。
